EG Games Android Studio starter project

Open this folder in Android Studio. Allow Gradle sync, then use Build > Build Bundle(s) / APK(s) > Build APK(s).

Requirements: Android Studio with Android SDK 35 and a compatible JDK/Gradle setup.
This is a starter project, not a compiled or signed APK. It wraps the supplied prototype in a WebView.
Bingo is opened externally using the referral URL; this project does not integrate with Bingo's private APIs.
The reward screen is a prototype and does not verify an actual Bingo registration or payment eligibility.
Before public release, verify reward terms, privacy policy, and the WhatsApp support number.
